# GallowsGameInstaller

Писал этот инсталлятор для нашей командной игры [Gallows Game](https://github.com/artikstur/gallows-game-maui). Это простая утилита на .NET MAUI. Надо было как-то упаковать билд и отдавать людям. Ничего лишнего.

**Зачем это вообще нужно**
Изначально мы просто пилили игру. Потом стало понятно, что кидать голый архив пользователям не очень круто. Решил набросать простенький визард. Он сам распаковывает нужные файлы. Плюс кидает ярлык на рабочий стол.

**Что под капотом**
Стек взял дефолтный. .NET 8.0 MAUI в связке с XAML и C#. Прикрутил еще пакет `CommunityToolkit.Maui` ради нормальных нативных окон выбора папки.

Как это все работает:

* У нас два варианта установки. Быстрая сразу на десктоп и кастомная через выбор директории.


* Окно лицензии. Без клика по соглашению дальше не пустит.


* В ресурсах тупо зашит архив `GallowsGame.zip`. Я его распаковываю средствами `System.IO.Compression` во временную папку. Потом уже перекидываю файлы на постоянное место.


* Индикатор выполнения обновляется асинхронно через `MainThread.BeginInvokeOnMainThread`. Интерфейс при установке не виснет.


* Создание ярлыков `.lnk` идет через COM библиотеку `IWshRuntimeLibrary`.


* После установки игра сама стартует. За это отвечает обычный `System.Diagnostics.Process`.



**Где лежит код**
Логика размазана по паре страниц. Стартовый экран живет в `MainPage.xaml`. Текст лицензии это `EULAPage.xaml`. Форма кастомного пути закинута в `InstallationSettingsPage.xaml`. А само ядро распаковки и математика процентов крутится внутри `InstallationPage.xaml`.

**Известные косяки**
MAUI формально поддерживает кучу платформ. В конфигах торчат настройки под Android, маки и Tizen. Но по факту инсталлятор заточен чисто под винду. Тут хардкодом прописано создание `.lnk` файлов и запуск `.exe` бинарника. Под другие операционки код не заведется из коробки. Тестов тоже пока нет. Руки не дошли.
